# Study Companion

An iPad-friendly PDF study prototype.

- Beyond Love: browser-side PDF text extraction and keyword search with page numbers.
- Anki Maker: separate page-by-page deck preview for each PDF.
- PWA manifest and service worker for Add to Home Screen.

## Current limitations
This is a prototype, not the complete requested app. It does not yet generate grounded natural-language answers, highlighted page screenshots, or genuine .apkg packages with embedded page images. PDFs are processed locally in the browser; there is no server-side upload or storage.

Serve over HTTPS and open in Safari.
